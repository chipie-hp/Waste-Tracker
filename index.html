Connect your GitHub account to back up data to a private Gist. Your data stays in your control. Works offline — changes sync automatically when you reconnect.

🔐 1. GitHub Personal Access Token

Create a token at github.com/settings/tokens → Generate new token (classic) → check gist scope only. Paste it below.

Your data is stored in a private GitHub Gist. If this is your first time, click Create Gist. If you already have one, paste the Gist ID below.
